# OmegaForge Studio 架构说明

OmegaForge Studio 用于把一个已有的智能体，提炼为**更强、更省**的新版本，并给出可复核的对比结论。

## 一、产品构成

本产品由三层组成，各层职责单一、边界清晰：

| 层 | 技术 | 职责 |
|---|---|---|
| 后端服务 | Python 标准库 | 蒸馏流水线、模型调用、数据持久化、对外接口 |
| 界面 | React + TypeScript | 十个工作面板，通过本地接口与后端通信 |
| 桌面外壳 | Tauri 2 | 启动并托管后端服务，提供原生窗口 |

后端**不依赖任何第三方 Python 包**，仅使用标准库，安装与打包成本低、供应链风险小。桌面外壳在应用启动时自动拉起后端服务，界面通过本地回环地址访问，不对外暴露端口。

│   ├── mcp_server.py        # 供外部智能体调用的服务
│   ├── core/                # 基础能力：预算、原子写入、输入校验、运行记录
│   ├── llm/                 # 模型接入、用量统计、上游地址校验
│   ├── distill/             # 蒸馏引擎、基因组、素材读取
│   ├── domain/              # 对照基线
│   ├── agent/               # 提炼产物的运行环境
│   ├── chat/                # 会话存储
│   ├── memory/              # 知识库、待办、资料库
│   ├── skills/              # 技能与人设管理

## 三、后端分层

### 1. 基础层

- **预算控制**：调用模型前先预估消耗，超出额度即中止，并保留分阶段用量台账。
- **原子写入**：所有数据文件先写临时文件再替换，避免中断产生半截文件。
- **输入校验**：所有来自界面、命令行、外部智能体的入参统一校验，非法值给出明确提示。
- **运行记录**：每次任务的全过程按事件流落盘，可回溯、可比对。

### 2. 模型接入层

支持多家模型服务商，按用途分为三档：

| 档位 | 用途 |
|---|---|
| 快速档 | 素材解析、压缩、出题、作答 |
| 主档 | 提示词合成 |
| 裁判档 | 对比评分（独立档位，避免自评） |

用量按阶段记账，界面可查看各阶段消耗与最耗时阶段。

### 3. 蒸馏流水线

一次完整任务依次经过以下步骤：

1. **读取素材**：从文件、目录或文本中提取源智能体特征，此步骤不消耗额度。
2. **解析**：把素材整理为结构化描述。
3. **压缩**：把描述凝练为可版本化的"基因"。
4. **合成**：由基因编译出新版提示词。
5. **出题**：按使命自动生成考题，覆盖典型、边界、压力三类。
6. **对比评测**：新旧版本同题作答，由裁判档模型评分。
7. **进化**：未胜出时分析差距、调整基因、重新合成，直到胜出或达到上限。

未胜出则不交付，且自动回退到上一版可用结果。

### 4. 能力与数据层

- **工具执行**：命令与文件操作受权限策略裁决，支持自动、询问、只读三档。
- **规则记忆**：用户授权的放行规则按作用范围记录，支持按会话、按项目、全局三档。
- **记忆**：知识库、待办、资料库，均支持检索与持久化。
- **语音**：可选的语音识别与合成，未安装相关组件时给出明确提示。

## 四、结论的可信判定

产品不宣称"一定更强"，而是把"更强"变成可复核的工程结论。

一次对比结论要成立，需要同时满足若干条件，其中最关键的两条：

- **裁判与作答不是同一个模型**，避免自我评分。
- **对照组真实可比**，即存在有效的原始提示词作为对照。

当任一条件不满足时，界面会明确说明原因，并给出对应的改进建议——例如更换裁判模型、提供原始提示词、补充考题等。**不会在不满足条件的情况下给出"更强"的结论。**

所有对比记录留档，支持任意两次任务之间的横向比对。

## 五、界面

界面包含十个工作面板：

| 面板 | 用途 |
|---|---|
| 蒸馏 | 发起任务、查看实时进度与日志 |
| 竞技场 | 查看对比结论与判定依据 |
| 基因组 | 查看与调整基因 |
| 运行记录 | 任务列表与详情 |
| 对话 | 与提炼产物直接对话 |
| 知识库 | 词条管理与检索 |
| 待办 | 任务清单 |
| 技能与人设 | 技能安装、人设查看 |
| 用量 | 各阶段用量与耗时统计 |
| 设置 | 服务商、权限、偏好配置 |

## 六、对外接口

后端提供 41 个本地接口，覆盖任务、对比、会话、知识库、待办、技能、权限、用量、语音等能力。

除界面外，命令行与供外部智能体调用的服务接入同一套后端能力，三者共享同一套入参校验与权限策略，行为一致。

## 七、设计取舍

- **后端零第三方依赖**：安装快、打包小、供应链风险低。
- **界面独立工程**：界面与后端分离，界面改动不影响后端，可独立构建。
- **基因可版本化**：基因以纯文本存储，可入库、可版本管理、可人工微调后重新编译。
- **权限内建**：工具执行与数据写入均受权限策略约束，外部调用与界面操作适用同一标准。
